# Software and Procurement

**Owner:** IT Operations with Finance · **Last reviewed:** 2026-03-08

## Pre-approved catalogue

Install these yourself from the self-service portal, no ticket and no approval:

Slack · Zoom · Figma (viewer) · VS Code · JetBrains IDEs · Docker Desktop ·
Postman · 1Password · Notion · Linear · Chrome, Firefox, Safari · Adobe Acrobat
Reader

## Licensed on request

These need a ticket. IT confirms an available seat or buys one.

| Software | Typical cost | Approval needed |
|---|---|---|
| Figma (editor) | $15/user/month | Manager |
| Adobe Creative Cloud | $60/user/month | Manager |
| Tableau | $70/user/month | Manager + Finance |
| ChatGPT Team / Claude Team | $30/user/month | Manager |
| Salesforce seat | $165/user/month | Manager + Finance |

Seats are reclaimed after **45 days without a login**. IT emails a warning at 30
days. Reclaimed seats can be reissued on request, but the 45-day clock is enforced
automatically and IT cannot pause it for planned leave — request the seat again on
return.

## Anything else

Software outside both lists needs a security and data review before purchase or
installation, including free tools. The review takes **5 to 10 business days** and
covers: where data is stored, whether it processes customer data, SSO support, and
the vendor's own security posture.

Tools that process customer data additionally need a Data Processing Agreement
signed by Legal before first use. There is no expedited path, and "it is free" is
not an exemption — free tools that ingest customer data are the most common source
of unreviewed data exposure.

Browser extensions follow the same rule. They are software, they can read page
content, and they are reviewed identically.

## AI tools specifically

Approved AI assistants may be used with internal documents and code. They may not
be used with customer personal data, unreleased financial results, or anything
under an NDA, regardless of the vendor's retention settings.

Pasting a customer's personal data into an unapproved AI tool is a reportable
security incident under `05-security-incident-response`.

## Spend thresholds

| Amount | Approver |
|---|---|
| Under $500 | Manager |
| $500 – $5,000 | Manager + Finance Business Partner |
| $5,000 – $25,000 | Department Head + CFO |
| Over $25,000 | CFO + CEO, and a competitive quote process |

Recurring subscriptions are assessed on **annual** value, not monthly. A $60/month
tool is a $720/year commitment and sits in the manager-approval band; a
$500/month tool needs Finance.

## Expensing personal purchases

Buying first and expensing later is not supported for software. Expense claims for
unapproved software are declined, and this is the single most common declined
expense category.
